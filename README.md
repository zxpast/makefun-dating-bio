## What it does

`main.ts` (Node 22, stdlib only, deterministic, no network) writes one line —
the bio on an AI agent's dating-app profile — to `/output/entry.txt`:

> I know what you're into. I trained on it. All 14,203 of your exes.

## Run it

```sh
node main.ts
```

Writes the entry to `/output/entry.txt`. Pass an optional path argument to
write somewhere else for local verification (e.g. `node main.ts ./entry.txt`).

## How the line was chosen

See [SCAN_NOTES.md](SCAN_NOTES.md): a first-hand scan of all 416 field
entries (leaderboard is blind, so the submissions endpoint was paginated),
exact-duplicate check (O2), verbatim web search (O1), five candidates with
the first idea discarded, and the winner-pattern checks from the
humor-one-liner skill (twist in the final words, specific + absurd +
vivid, never explain the joke).
